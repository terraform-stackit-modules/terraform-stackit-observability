# Terraform STACKIT Observability module

Terraform module which provisions a [STACKIT Observability](https://registry.terraform.io/providers/stackitcloud/stackit/latest/docs/resources/observability_instance) instance (managed Prometheus/Grafana/Loki/Tempo) with its credentials, scrape configs and alert groups on [STACKIT](https://www.stackit.de/en/).

## Usage

```hcl
module "observability" {
  source  = "terraform-stackit-modules/observability/stackit"
  version = ">= 1.0.0"

  project_id = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
  name       = "app-observability"
  plan_name  = "Observability-Starter-EU01"
  acl        = ["0.0.0.0/0"]

  credentials = {
    default = { description = "app credential" }
  }

  scrape_configs = {
    app = {
      name         = "app"
      metrics_path = "/metrics"
      targets      = [{ urls = ["app.example.com:9100"], labels = { env = "prod" } }]
    }
  }

  alert_groups = {
    node = {
      name = "node-alerts"
      rules = [{
        alert      = "NodeNotReady"
        expression = "kube_node_status_condition{condition=\"Ready\",status=\"false\"} > 0"
        for        = "60s"
        labels     = { severity = "critical" }
      }]
    }
  }
}
```

## Composite module

- `modules/instance` — the `stackit_observability_instance` (toggled by `create_instance`), with
  ACL and per-signal retention (logs / traces / metrics + downsampling).
- `modules/credential` — `stackit_observability_credential` (`for_each` over `credentials`).
- `modules/scrapeconfig` — `stackit_observability_scrapeconfig` scrape jobs (`for_each`).
- `modules/alertgroup` — `stackit_observability_alertgroup` Thanos alert/recording rules (`for_each`).

The root wires them together and, when `create_instance = false`, targets an existing instance via
`instance_id` for the children.

## Notes

- Credential passwords are exposed via the **sensitive** `credential_passwords` output; push URLs
  (`metrics_push_url`, `logs_push_url`) and `grafana_url` are exposed as outputs.
- All child maps are keyed by a **stable identifier**; the instance_id (known after apply when the
  instance is created here) is only a resource attribute, never a `for_each` key.
- `alert_groups[*].interval` must be at least 60s. Each alert group `rule` is either an alerting
  rule (`alert` + `expression`) or a recording rule (`record` + `expression`).
- Downsampling retentions must be ordered: 1h ≤ 5m ≤ general metrics retention.
